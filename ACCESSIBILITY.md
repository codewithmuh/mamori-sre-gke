# Accessibility

The documentation in this repo aims to be usable with a screen reader, without colour, and at any zoom level.

- **Structure:** GitHub-flavoured Markdown with real headings, lists and tables.
- **Diagrams:** architecture sketches are plain-text diagrams, and the prose next to each one describes the same flow,
  so nothing is only in a picture.
- **Images:** screenshots and charts, when they arrive, get alt text that states what they show.
- **Colour:** status is always given in words or symbols, never by colour alone.

The demo shop itself is Google's Online Boutique, used unchanged apart from a banner; its accessibility is upstream's.

Found a barrier? Open an issue, or email [contact@codewithmuh.com](mailto:contact@codewithmuh.com).
