# Runbooks

One page per alert or operational procedure. Every alert links to its runbook. Each runbook answers: **what is
broken, how bad is it, how to confirm, how to mitigate, how to escalate.**

| Runbook | Use it when | Status |
|---|---|---|
| [spend-guard.md](spend-guard.md) | Spend guard fired: node pool scaled to zero (budget reached); how to tell, and how to resume (`make resume`) | Arrives with #7 |

Runbooks for the journey SLO burn-rate alerts arrive with M2 (#10); incident roles, severity levels and the
postmortem template with M3 (#11).
